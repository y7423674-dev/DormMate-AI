# DormMate AI

DormMate AI 是一个面向学生宿舍的协作看板 Demo，用来管理宿舍值日、缴费、洗晒、公告和成员状态。项目基于 Next.js 构建，数据以宿舍邀请码为单位保存，适合做原型演示和功能测试。

## 本地启动

先安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

然后在浏览器访问：

```text
http://localhost:3000
```

也可以运行生产构建检查：

```bash
npm run build
```

## 如何登录

本项目是 Demo 原型，不需要注册账号，也没有密码登录。

1. 打开首页后，输入你的昵称。
2. 输入宿舍邀请码，默认示例邀请码是 `DORM-402`。
3. 选择身份：`舍友` 或 `舍长`。
4. 点击进入宿舍空间。

进入后，系统会把当前用户会话保存在浏览器本地。下次打开时会自动进入对应宿舍。

如果想重新开始，可以在首页点击“恢复初始状态”，或在“我的”页面清空本地缓存、切换宿舍。

## 如何使用

### 首页看板

首页展示当前宿舍概况，包括：

- 宿舍公告
- 舍友状态
- 今日任务进度
- 值日、收衣、缴费等待办事项

可以直接在首页完成部分任务，例如确认值日完成、确认收衣，或跳转到缴费页面处理缴费。

### 值日

在底部导航点击“值扫”进入值日页面。

可以查看昨天、今天、明天的值日安排。如果今天轮到自己值日，可以点击“我已完成”完成值日，也可以进入换班页面发起换班。

### 缴费

在底部导航点击“缴费”进入缴费页面。

可以查看本月支出记录，并新增支出。新增支出时支持：

- 全员平摊
- 仅我支付
- 按比例收费

日历中有支出的日期会显示标记，点击某一天可以查看当天支出情况。月报分析会把公共开支和个人开支分开统计。

### 洗晒

在底部导航点击“洗晒”进入洗晒页面。

可以查看天气和洗晒建议、阳台占用情况，以及登记自己的晾晒物品。登记后可以设置预计收衣时间，收衣后点击“我要收衣”释放阳台位置。

### 公告

从首页公告入口进入公告页。

可以查看置顶公告、标记已读，也可以新增公告。公告会显示已读人数，方便确认舍友是否看到。

### 我的

在底部导航点击“我的”进入个人页面。

可以查看当前宿舍邀请码、昵称和身份，也可以复制邀请码、切换宿舍或清空本地缓存。

### AI 助手

页面右下角有 AI 入口，可以输入宿舍事务相关指令，例如登记晾晒、确认缴费、发布公告、更新状态等。AI 会根据指令尝试更新宿舍数据。

## 角色说明

- 舍友：可以查看和完成自己的任务，登记洗晒、确认缴费、发布公告等。
- 舍长：拥有更高管理权限，例如可以删除缴费记录。

## 数据说明

这是一个 Demo 项目，数据用于本地开发和演示。用户会话保存在浏览器本地，宿舍状态通过项目内 API 读写。不要把它当作正式生产系统使用。
